Quokka

作为 Windows 靶机的初次尝试者，我对 Windows 系统的整体架构和特有工具有些生疏。这次通过对定时任务（.bat）的利用以及反弹 Shell 的调试，算是迈出了熟悉 Windows 渗透的第一步。

信息搜集

端口扫描

  • 80 http
  • 135 MSRPC
  • 139 NetBIOS
  • 445 SMB
  • 5945 WinRM
  • 47001 WinRM 备用端口
  • 49664-49682 RPC

‍

枚举

SMB

有个Compartido共享目录

有两个.bat文件，在windows中.bat相当于Linux中的.sh

所以优先查看这两个文件

查看一下这两个文件

mantenimiento.bat这个脚本里插入了一行 PowerShell 反弹 Shell（Reverse Shell）命令。且每分钟会执行

  • 参数解析​：-NoP​ (不加载配置文件), -NonI​ (非交互模式), -W Hidden​ (隐藏窗口), -Exec Bypass (绕过脚本执行策略)。
  • 行为​：它会尝试从攻击机（IP 为 192.168.1.36​，端口 8000​）下载一个名为 shell.ps1​ 的脚本，并直接在内存中执行（iex）。

所以这里我们可以修改ip为自己的ip下载一个反弹shell脚本来获取shell

创建一个反弹shell文件,这里使用的是这个https://github.com/MartinSohn/PowerShell-reverse-shell/blob/main/powershell-reverse-shell.ps1
需要修改ip和端口号为自己反弹shell机器的

使用python起一个web服务

修改mantenimiento.bat里面的ip为自己反弹shell文件机器的ip

在起一个监听反弹shell服务，这里我使用的是penelope.py当然也可以使用nc

上传mantenimiento.bat等待下载反弹shell文件触发

可以看到成功触发
