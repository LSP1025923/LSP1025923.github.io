Runers

信息搜集

192.168.100.59

端口扫描

2222也是openssh的

‍

目录扫描

值得注意的是post.php

可能存在sql注入

3个user，但是密码是md5加密过的，需要解密

https://crackstation.net/

只有一个可以解密成功

david:runner

‍

提权

david -> maria

ssh登录,需要注意的是这里端口是2222

‍

在david用户的家目录下存在一个hidden的隐藏文件夹里面有一个credenciales.zip

解压发现需要密码

将credenciales.zip 给get到kali使用john爆破

爆破

密码是 rockandroll

解压发现有个xlsx文件

我将他get到本地Windows上查看发现了凭证

‍

‍

maria -> root

在maria用户家目录下同样存在隐藏文件 .viminfo(是 Vim 编辑器的状态历史记录文件)

可以看到都是一些关于/opt/scripts/backup.sh的

是一个备份数据的sh脚本同时我们还有权限修改。同时上传pspy

可以看到root一直在执行/opt/scripts/backup.sh

那么我们可以写入利用脚本到backup.sh给/bin/bash加权限

‍

当时以为到这结束了但发现并没有因为我们还在docker里面，这就解释了为什么有两个ssh端口2222是映射出来的

所以现在需要docker逃逸

‍

docker逃逸

root -> ian

在root用户目录下TODO_LIST.txt给出了用户名和密码

  1. Crear un script para automatizar los backups de la base de datos. (OK)
  2. Cifrar las contraseñas de la base de datos. (OK)
  3. Avisar a Ian para que cambie su contraseña, a ver si deja usar su famosa contraseña “iambatman” en todos lados. (Pendiente)

ian:iambatman

‍

ian -> elliot

在/home/elliot目录下有一个psafe3文件(是一个由 Password Safe 软件创建的加密密码库文件)

解密他需要用户名和密码，但是现在缺少密码，这里可以使用pswafe2john 提取哈希值并破解

elliot:metallica

输入密码

然后copy 4个密码

Fs5v3MO6E8GTJTJ
HwbE80ZOtZQdkYB
be8RxKniyGXYb2L
lHIiAIVFONoFjpl

经过尝试发现HwbE80ZOtZQdkYBs是用户elliot的密码

‍

elliot -> root

使用docker组提权

https://gtfobins.org/gtfobins/docker/
