现在缺少利用的方式

二次信息搜集

上传linpeas.sh

当前有一个root运行py的进程

脚本功能拆解

这个 Python 脚本执行了以下操作：

  1. 读取私钥： 尝试打开 /home/backupd/.ssh/id_ed25519​。这是 backupd 用户的 Ed25519 格式私钥

  2. 建立 UDP 广播： 配置了一个 UDP 套接字，并开启了广播模式 (SO_BROADCAST)。

  3. 全网发射： 将私钥的完整文本发送到广播地址 255.255.255.255​ 的 9999 端口。

    • 这就是为什么之前可以使用wireshark抓到私钥

  4. 无限循环： 每隔 30 秒执行一次。

  5. 日志记录： 它会将成功或失败的状态写入 /home/backupd/logs/broadcast.log。

    • 注意： 脚本用了 "w" 模式

可以创建一个backupd用户可控的broadcast.log​利用软链接将/home/backupd/logs/broadcast.log​链接到/etc/ssh/sshd_config.d/deny-admin.conf那么就可以覆盖限制admin登录的权限。这和之前的link2靶机有点类似都是利用链接。

重启（因为ssh服务是存在于进程里面的，只有重启ssh服务或者重启服务器才能更新配置文件）

admin -> root

同时/usr/local/bin/broadcast_key.py文件admin具有修改权限，又是root运行的可以利用这点进行提权

依旧利用reboot重启
