main函数

主函数逻辑

  1. 定义目标密文 v13[0]、v13[1]、v14（共 20 字节）
  2. 调用 generate_key() 生成 RC4 密钥
  3. 使用 scanf() 读取用户输入
  4. 调用 rc4_init() 初始化 RC4 状态
  5. 调用 rc4_crypt() 加密用户输入
  6. 比较加密结果与目标密文（逐字节比对）
  7. 验证成功则调用 get_shell()

密钥生成函数

密钥推导过程：

字符串 “认符星” 的 UTF-8 编码转换为十六进制：

每个字节与 0xAA 进行异或运算：

最终密钥 : “believe”

RC4 初始化函数

参数说明 ：

  • a1 : RC4 状态数组指针（S-box）
  • a2 : 密钥指针
  • a3 : 密钥长度（7）
    初始化过程 ：
  1. 第一层循环：用 0-255 初始化 S-box
  2. 第二层循环：基于密钥打乱 S-box

RC4 加密函数

加密过程 ：

  1. 初始化计数器 i = 0, j = 0

  2. 对每个字节：

    • i = (i + 1) % 256
    • j = (j + S[i]) % 256
    • 交换 S[i] 和 S[j]
    • 密钥流字节 K = S[S[i] + S[j]]
    • 明文字节与 K 异或得到密文

Shell 解密过程 ：

  • 原始值： 0x8C9E9DD091969DD0
  • 按字节取反： ~0x8C = 0x73 = ‘s’ , ~0x9E = 0x61 = ‘h’ , …
