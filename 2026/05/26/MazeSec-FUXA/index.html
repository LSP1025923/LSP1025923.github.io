FUXA

作者：hel2zy

难度：Easy

信息搜集

192.168.43.201

端口扫描

  • 22 SSH

  • 80 HTTP

  • 1881 HTTP(FUXA)

80和1881的页面是一样的，但是FUXA默认端口是1881所以从1881开始

‍

目录扫描

‍

版本泄露

FUXA 是一个基于 Web 的 SCADA / HMI 平台， 用于工业自动化、物联网和实时过程可视化。

1月16日有个漏洞但是目前并不知道版本所以不能确定

main.a17204bdf90c1b7a.js中泄露了版本号

CVE-2026-25938。由于网上还没有现成的利用脚本，所以这里写了一个反弹shell的python利用脚本

参考 https://cvereports.com/reports/CVE-2026-25938

‍

提权

www -> git

上传pspy查看定时任务

可以看到UID=1001的用户也就是git用户执行了/opt/fuxa/FUXA/server/scripts/local-sync.sh

泄露了git用户的密码

横向移动到git用户

‍

git -> root

在/opt/.cache-loader/state/下的目录结构

可以确定这是一个 Git 仓库

里面有个 .slots/icons​ 文件本质上是一个 索引映射表它将程序需要的“逻辑资源名称”映射到了 Git 的对象哈希值上

查看hash

使用git cat-file导出stable对应的对象

已经获得了root的私钥
