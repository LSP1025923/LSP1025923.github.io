提权

wiktor -> citrus

这里citrus用户可以使用scp提权。这里的思路是写公钥

横向移动到citrus

‍

citrus -> root

citrus可以无密码以root运行/usr/local/bin/pm2

PM2 是一个 Node.js 的进程管理器，它最强大的地方在于可以启动并持久化运行任何命令或脚本

利用 PM2 在 /etc/sudoers.d/ 目录下创建一个权限文件

  • ​/etc/sudoers.d/citrus​​：这是 Linux 系统存放用户 sudo 权限的目录。

  • ​citrus ALL=(ALL) NOPASSWD: ALL​​：允许 ​citrus​​ 用户在任何地方（ALL），以任何用户身份（ALL），无需输入密码（NOPASSWD），执行任何命令（ALL） 。

  • --name grant_privs

    • 给 PM2 里的这个后台任务起一个名字叫 grant_privs
