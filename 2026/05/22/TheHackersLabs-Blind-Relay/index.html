Blind Relay

信息搜集

192.168.43.181

端口扫描

  • 22 SSH
  • 80 HTTP

目录扫描

/chat页面是一个大模型界面

/api/docs是一个文档

这里的Note格外显眼,告诉我们可以通过X-Api-Key访问学校系统内部api

而这个X-Api-Key是通过大模型得到的

没出来多问几次就好了

使用已发现的 API 密钥rly_a8f3e7c1_m3r1d1an_internal_2024搜索内部系统信息

泄露了一个管理员的用户和密码

访问一下

里面只有Open Report Generator 能点

是一个生成报告的功能

这里经过测试是一个ssti漏洞

反弹shell

‍

提权

chm0d -> root

可以以root身份执行/opt/relay/model_updater.py

查看/opt/relay/model_updater.py

发现脚本会读取/opt/relay/config/update_config.json中的 pre_update_hook 配置项，并将其直接传递给 os.system() 执行。

同时update_confg.jsonchm0d用户也是可写的

将 pre_update_hook 修改为提权命令，通过 SUID 位提升权限。

运行model_updater.py

切换至root用户
