提权

docker www -> b2

在b2用户的家目录下.profile给出了hint

可以使用/opt/pro.so提权

仅允许标准代理和授权的维护路径

前面又提示我们定时任务，那么这题大概率就是利用定时任务了

该程序正在监听本地的所有网卡（0.0.0.0​）的 9876 端口，任何发送到这台机器 9876 端口的数据，都会被以 root 权限 转发到指定的 192.168.1.100:80

由此可以判断是使用socat编写的程序，当输入 TCP:192.168.1.100:80​ 时，脚本中的正则匹配成功，最终执行的底层命令是：sudo socat TCP-LISTEN:9876,reuseaddr TCP:192.168.1.100:80​这是 socat​ 最经典的 端口转发（Port Forwarding） 语法。

那么可以利用socat的文件与流操作类CREATE: CREATE:<path>​。创建并写入文件因为任何发送到这台机器 9876 端口的数据，都会被以 root 权限 转发到指定的 192.168.1.100:80，那么可以写入定时任务
