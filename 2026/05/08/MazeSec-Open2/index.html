失败返回NOT FOUND​成功返回SUCCESS。使用sql拖库

youareuser

ssh登录bingren用户发现登录不上，主页也同样登录不上

这是因为刚刚我们sql注入出来的数据中可以看到knock，而knock是一种在服务器上隐藏安全服务端口的防御机制

在默认情况下，服务器上的某些敏感端口（比如 SSH 的 22 端口、或者某些后台管理端口）在防火墙（iptables​ / firewalld）里是完全关闭（DROP）的，你直接去连接或扫描它，会显示端口关闭或超时。

但是，服务器后台运行着一个守护进程（通常是 knockd​），它在默默监听网卡的流量。如果你按照特定顺序、往特定的端口发送一串探测包，knockd​ 就会识别出这个“暗号”，并自动修改防火墙规则，​临时为你（也就是你的 IP）开放那个隐藏的端口。

这里临时换网所以ip变了凑合着看吧

​cap_dac_read_search​：这个特权允许程序绕过文件的读权限检查（DAC，Discretionary Access Control）以及目录的搜索/执行权限检查。

通俗解释：这意味着，带有这个权限的 wget​ 可以读取系统上的任何文件，即使该文件属于 root 且设置了 600​（仅 root 可读写）权限。例如，它可以读取 /etc/shadow（哈希密码文件）或者 root 用户的 SSH 私钥。

我们可以启动一个本地监听器，或者让 wget​ 将敏感文件作为 POST 请求的数据发送到我们的监听端口（或者直接保存到本地，但 wget 主要是网络传输工具，最直接的方法是发送到本地环回口或你自己的 Kali 机上）。
