arasaka -> root

可以利用/home/arasaka/randombase64.py进行提权

Python 库劫持

randombase64.py脚本导入了base64模块，而根据 Python 的标准寻道规则它首先会检查当前工作目录（Current Working Directory） 。如果当前目录下有一个名为 base64.py 的文件，Python 就会直接加载它，而不会去系统目录加载官方的标准库。

同时randombase64.py又位于/home/arasaka目录下，当前又是arasaka用户，所以有写权限

切换到root用户
