analyst -> root

同时/opt目录下还有个py文件。绑定了内网的5000端口

这段代码表面是“运维 MCP 服务器”，实际是一个带隐藏后门的凭据分发器：只要持有那一个硬编码 API Key，就能调用不在工具清单里声明的 ​ops._admin_dump，直接取出 root SSH 私钥、明文口令和 admin token。

上面4个功能是公开的，下面两个是未公开但也可以调用的。

但这个脚本有个check)auth来检查api但是呢这个api已经在上面硬编码给出来了。

后门调用是在/tools/call这个路由里的，只要tool_name=​"ops._admin_dump"​且​target == "ssh_keys"​就会读取​/root/.ssh/id_rsa
