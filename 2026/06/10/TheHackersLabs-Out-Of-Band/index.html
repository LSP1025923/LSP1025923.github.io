信息搜集

192.168.100.39

端口扫描

  • 22 SSH
  • 2222 SSH (docker映射出来的)
  • 2375 Docker Remote API
  • 8080 HTTP (docker映射出来的)

2375存在Docker远程API未授权访问，所以可以利用这个未授权访问查看docker内部容器

只有一个ctf-target-v2:latest容器

使用exec -it访问docker内部

提权

docker root -> root

现在需要docker逃逸到宿主机，既然2375存在未授权那么可以启动一个新容器挂载宿主机的根目录

直接利用本地镜像挂载
